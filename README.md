弈剑行（Yijianxing）
弈思沧海定三先，侠出红尘磨一剑。
江湖犹在，莫问归期。见招拆招的传统武侠风格联机对战。
🎮 项目简介
《弈剑行》是一款以传统武侠见招拆招为核心的独立游戏，主打高自由度的招式组合、实时联机对战与沉浸式武侠体验。游戏以水墨国风为基调，还原了武侠世界中「见招、拆招、变招」的核心博弈逻辑，支持单机挑战与多人联机对战，是一款真正意义上的「武侠格斗」作品。
本仓库为《弈剑行》开源项目存档，完整保留了游戏从开服到迭代的全部历史版本与核心更新日志，供玩家回顾、开发者学习与二次创作。
🛠️ 技术栈
游戏引擎：Unity
核心玩法：实时动作格斗、联机对战、单机生存 / 擂台挑战
交互系统：招式连招系统、拆招 / 弹刀机制、变招系统
网络功能：跨平台联机、好友对战、4 人混战、聊天系统
其他特性：UI 自定义、防沉迷系统、实名认证、支付系统
🚀 运行方式
网页版（当前仓库版本）
直接下载仓库中的 弈剑行2.html 文件
使用任意现代浏览器（Chrome、Edge、Firefox 等）打开文件
即可进入游戏，无需额外环境配置
原生客户端（历史版本）
历史 Unity 客户端可通过 TapTap 等平台下载历史版本
开源版本可基于本仓库代码，使用 Unity 引擎重新编译打包
📋 核心特性
✅ 核心战斗系统：见招拆招、弹刀机制、变招连招，还原真实武侠博弈
✅ 多模式玩法：联机对战、好友切磋、4 人混战、竹林伏击、校场点兵、宗师论道
✅ 丰富武器系统：多武器招式体系，支持自定义预设与变招组合
✅ 联机功能：跨平台合服、排位赛、江湖排行榜、好友邀请
✅ 自定义设置：出招提示、拆招提示、隐藏 UI、简化连招、画质调整等
✅ 完整更新迭代：从单机测试到联机开服，全版本更新日志完整保留

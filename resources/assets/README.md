# 📌 项目简介
《弈剑行》是一款以传统武侠**见招拆招**为核心的独立游戏。
游戏主打高自由度的招式组合、实时联机对战与沉浸式武侠体验。

以水墨国风为主，还原武侠世界中「见招、拆招、变招」的核心博弈逻辑。
支持单机生存、擂台挑战、联机对战、好友切磋等多种模式。

本仓库为《弈剑行》开源存档项目，完整保留了游戏从开服到停服的所有版本日志与历史更新记录，可供玩家回顾、学习及二次创作。

---

# 🧩 核心特性
- 见招拆招、弹刀机制
- 变招连招系统
- 多武器招式体系
- 拆招、弹虚、反震等战斗逻辑
- 联机对战 / 好友切磋 / 混战模式
- 竹林伏击、校场点兵、宗师论道（单机）
- 出招提示、拆招提示、UI 隐藏等自定义设置
- 完整版本更新历史（2021–2025）

#  运行方式
## 网页版（本仓库）
直接下载或打开：
**弈剑行.apk**

手机端打开即可游玩，无需额外环境。

## 原生客户端（历史版本）
原 Unity 版本可通过 TapTap 等平台下载历史客户端。
开源版本可基于本仓库代码使用 Unity 重新编译打包。
